# Sessions — currículo por tema

Ruta recomendada para estudiar de cero. Cada carpeta agrupa la teoría y los
ejercicios de un bloque. Para el registro cronológico clase a clase, ver
[`../classes/`](../classes/).

| # | Carpeta | Tema |
|---|---------|------|
| 1 | [`01-c-basico/`](01-c-basico/) | Introducción a C: hola mundo, capicúa, punteros y memoria |
| 2 | [`02-c-ejercicios/`](02-c-ejercicios/) | Ejercicios en C: `logic/`, `pointers/`, `complex/` (archivo plano, Montecarlo) |
| 3 | [`03-openmp/`](03-openmp/) | OpenMP: hilos, `reduction`, primos en paralelo, `demo-secuencial-vs-paralelo/` |
| 4 | [`04-mpi/`](04-mpi/) | MPI: test de entorno, suma de arreglo distribuida |
| 5 | [`05-segmentacion-imagenes/`](05-segmentacion-imagenes/) | Segmentación de imágenes PPM en paralelo con OpenMP |
